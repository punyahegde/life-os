# Life OS — iPhone Web App

This is a Mac-free web/PWA implementation based on the routine and feature structure in the Antigravity Life OS build.

## Run
Serve this folder from HTTPS (GitHub Pages is a simple option), then open the URL in Safari on iPhone and choose **Share → Add to Home Screen**.

## Notes
- Data is stored locally in the browser.
- Career tracker, routine checklist, weekly progress and streaks are included.
- Browser notifications require HTTPS and permission; iPhone web push has additional iOS/Home Screen requirements.
